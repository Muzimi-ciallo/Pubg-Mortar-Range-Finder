# PUBG 地图倍率测距工具

这是一个精简的可点击悬浮窗测距工具。它按当前 Windows 桌面分辨率自行调整缩放，不读取或修改游戏内存。

## 运行

```powershell
python -m pip install -r requirements.txt
python map_distance_tool.py
```

## 使用

1. 打开 PUBG 大地图，在控制窗口选择地图尺寸和当前缩放倍率。
2. 将鼠标放在起点，按住 `Ctrl+H`；起点会固定在按键瞬间的位置，终点实时跟随鼠标。
3. 松开 `H` 后线段和距离立即消失。测量过程中不需要点击地图。
4. 点击悬浮窗的“设置”可以自定义测距组合键和循环倍率键，格式如 `ctrl+h`、`alt+z`；默认 `F6` 循环倍率。

实际距离取决于游戏 UI 缩放、窗口模式和地图是否完整铺满预期区域。如果你的客户端比例与预设存在偏差，建议用地图上已知的 100m 网格核对结果。
